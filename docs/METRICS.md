# Метрики автоматических потоков

## Время

- `planned_stage_hours` — оценка трудоёмкости текущего ограниченного этапа.
- `actual_runtime_hours` — только подтверждённое время выполнения запусков.
- Время между расписанием и отчётом не считается вычислительным временем.
- Если длительность запуска недоступна, записывается `null`.

## Прогресс

Процент этапа считается только по принятым критериям:

`progress = passed_acceptance_weight / total_acceptance_weight × 100`

Количество файлов, коммитов и сообщений само по себе прогрессом не является.

## Загрузка

- `capacity_utilization = active_streams / capacity`;
- `redirect_count` — число переназначений;
- `blocked_hours` — подтверждённое время блокировки;
- `rework_ratio` — исправления после FAIL / все завершённые шаги;
- `evidence_coverage` — результаты с источником и проверкой / все результаты;
- `green_rate` — успешные приёмочные запуски / все приёмочные запуски.

## Статусы

- `active` — поток выполняет назначенную работу;
- `reserve` — мощность свободна;
- `paused` — работа сохранена, но запуск отключён;
- `redirected` — поток передан другой фабрике;
- `blocked` — продолжение требует внешнего решения;
- `completed` — этап прошёл приёмочный gate.
