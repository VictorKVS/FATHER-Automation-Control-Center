# Модель мощности автоматических потоков

Модель отвечает на вопрос: сколько займёт одна задача, если направить на неё от
одного до пяти потоков. Она применяется только после разбиения задачи на
независимые пакеты с единым контрактом результата.

## Формула

```text
эффективная мощность = потоки × коэффициент эффективности
время работы = трудоёмкость / эффективная мощность
интеграция = базовая интеграция × (1 + 0,15 × (потоки − 1))
общий срок = время работы + интеграция
```

Коэффициент снижается с ростом числа потоков из-за синхронизации, конфликтов,
повторной проверки и объединения результатов. Поэтому пять потоков не дают
пятикратного ускорения.

## Границы доказанности

- Плановое и фактическое время не смешиваются.
- Прошлое время исполнения неизвестно, если автоматизация не экспортировала
  длительность запуска.
- В `workload_history.csv` такие значения оставлены пустыми.
- Коэффициенты версии 1.0 являются инженерной оценкой.
- После накопления минимум 20 сопоставимых запусков коэффициенты следует
  пересчитать по медиане и P80 фактического времени.

## Что измерять дальше

Для каждого запуска нужны `started_at`, `finished_at`, объём входа, сложность,
количество обработанных сущностей/документов, PASS/FAIL, rework и затраты на
интеграцию. Тогда появится фактическая скорость: документов, узлов, событий или
приёмочных пунктов за подтверждённый час.
