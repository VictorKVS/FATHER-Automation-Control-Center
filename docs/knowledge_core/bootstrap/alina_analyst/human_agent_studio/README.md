# FATHER Human Agent Studio

Status: PRE-IMPLEMENTATION BASELINE  
Reference Agent: **ALINA #001**

## Mission

Human Agent Studio turns natural multimodal intent into a versioned, testable interactive digital specialist. The human communicates primarily through conversation, images, sketches, references and corrections; technical prompts, scene actions, runtime instructions and production artifacts are compiled internally.

The first complete Human Agent is ALINA #001. Studio capabilities are accepted only after they work on ALINA.

## Product principle

**Conversation first. Inspector when precision is needed. Avatar optional. Knowledge and professional truth remain outside the renderer.**

## Core loop

USER INTENT + REFERENCES
→ SCENARIO WRITER
→ VISUAL / MULTIMODAL INTENT
→ 3D / HUMAN AGENT / GAME EXPERIENCE ENGINEER
→ PRODUCTION COMPILER
→ TOOLS / RUNTIMES
→ PREVIEW
→ USER FEEDBACK
→ DELTA UPDATE
→ VALIDATION
→ VERSIONED RESULT

## Interaction modes

- FLOW — default natural collaboration with minimal questions.
- DETAIL — meticulous discussion of a selected feature.
- LOCK — approved characteristic becomes a versioned constraint.

## Build strategy

Default: HYBRID.
- Reuse mature commodity infrastructure through adapters.
- Adapt when integration/provenance/testing require it.
- Build FATHER-specific semantic/orchestration/knowledge layers.
- Build small educational implementations when needed to understand and benchmark a mechanism.

## Runtime direction

- Web: React + Three.js / React Three Fiber.
- Character interchange: VRM plus GLB/glTF compatibility.
- DCC: Blender-first.
- Game runtime: evaluate Godot/Unreal adapters after reusable contracts stabilize.
- Providers for LLM/TTS/STT/generation remain replaceable.

## Definition of success

The Studio is not successful because editors exist. It is successful when ALINA #001 can be reproducibly assembled, embodied, controlled, conversed with, visually directed from references, revised by natural-language feedback, validated and reproduced from versioned artifacts.
