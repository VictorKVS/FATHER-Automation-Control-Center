# ALINA #001 — local avatar asset slot

The browser runtime loads the temporary avatar from this local application asset directory. The binary VRM is intentionally not created by a text-only repository mutation.

Expected development file:

`Seed-san.vrm`

Acquisition is performed by `scripts/GET_ALINA_TEST_AVATAR.ps1`, which downloads the official VRM Consortium sample, calculates SHA-256 and leaves the model locally in this directory.

The temporary sample is **not the permanent appearance of ALINA #001**.

Before redistribution or production promotion, verify the current model metadata and license terms. Seed-san is documented by its sample README as a VirtualCast, Inc. model under VRM Public License 1.0; this is not CC0. Preserve required attribution and do not silently reclassify the asset.
